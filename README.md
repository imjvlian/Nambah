# Nambah

Nambah adalah web top up digital yang dibangun dengan Next.js.

## Status

MVP awal — katalog dan alur top up frontend.

## Development

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Roadmap

- Katalog game dan produk
- Integrasi supplier (Digiflazz)
- Payment gateway
- Webhook transaksi
- Tracking order
- Admin dashboard
